# APEXlang

Resources for **APEXlang**, the application definition language introduced with **Oracle APEX 26.1**.

APEXlang is a declarative, human-readable language for defining Oracle APEX applications: pages, navigation, forms, reports, dashboards, shared components and business logic. Instead of asking an AI agent to emit implementation code (PL/SQL, JavaScript, HTML), you ask it to generate or edit an APEXlang definition, and Oracle APEX compiles and runs that definition in its managed runtime. Because the definition is plain text, it can live in source control, be diffed, reviewed, validated and promoted like any other artifact.

> **Requirements:** Oracle APEX **26.1** (26.1.2 or later), plus SQLcl or SQL Developer for VS Code to install and compile APEXlang-based applications.
